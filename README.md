A responsive dashboard application that brings together multiple mini-applications (widgets) into a single interface. The application consists of Notes, Calendar, and Weather widgets.

The application supports multiple users and was developed using React. The responsive user interface was built with CSS Grid, ensuring an optimal experience across different screen sizes. Google Firebase was used for user authentication as well as secure storage of user data and notes. The application was deployed using GitHub Pages and includes Progressive Web App (PWA) support for an improved mobile experience.
